   - Tracks `last_inbound_seq`, `last_outbound_seq`, `last_acked_message_id`, `last_sent_command_id`, `last_sent_command_type`, `last_sent_command_payload`, `resend_count`, `processed_message_ids`, and `session_expires_at`.
   - Generated and tested reversible Alembic migration `002_protocol_cursors.py` (`upgrade` and `downgrade` verified in migration test suite).

2. **Protocol Persistence Repository (`app/persistence/repositories.py`):**
   - Implemented `ProtocolRepository` supporting:
     - `get_or_create_cursor`: Atomic cursor retrieval and TTL initialization.
     - `record_inbound`: Atomically records inbound sequence number, appends to `processed_message_ids`, and refreshes TTL.
     - `record_outbound`: Durably stages last sent command payload and outbound sequence.
     - `record_ack`: Records client acknowledgment and marks command ACKed.
     - `increment_resend`: Atomically increments `resend_count` for bounded resend enforcement.
     - `is_message_processed` and `is_session_expired`: Timezone-safe idempotency and expiry checks.

3. **Observable Reason Codes & Protocol Models (`app/device_protocol/`):**
   - `ProtocolReasonCode` enum: `ACCEPTED`, `DUPLICATE_MESSAGE`, `OUT_OF_ORDER_SEQUENCE`, `SEQUENCE_GAP`, `STALE_STATE_VERSION`, `STALE_TURN`, `SESSION_EXPIRED`, `SESSION_NOT_FOUND`, `SESSION_TERMINAL`, `INVALID_PROTOCOL_VERSION`, `MAX_RESENDS_EXCEEDED`, `ACK_MISMATCH`, `UNEXPECTED_ENVELOPE_TYPE`, `CORRUPT_ENVELOPE`.
   - `ProtocolValidationResult`: Structured outcome of validation containing validity bool, reason code, error message, and duplicate/stale/reorder flags.
   - `ResumeResponse`: Reconnection recovery contract containing `session_id`, `status` (`RESUMED`, `TERMINAL`, `EXPIRED`), `resumed_state`, `state_version`, `turn_number`, `pending_command` (if un-ACKed and under retry cap), and durable `resend_count`.

4. **Transport-Neutral Protocol Sequencer (`app/device_protocol/sequencing.py`):**
   - Validates incoming envelopes against protocol version (`1.0`), session validity, terminal states, and TTL expiration.
   - Enforces monotonic sequence numbers (`envelope.seq == cursor.last_inbound_seq + 1`), rejecting reordered packets (`OUT_OF_ORDER_SEQUENCE`) and packet loss gaps (`SEQUENCE_GAP`).
   - Deduplicates messages using persisted message IDs (`DUPLICATE_MESSAGE`).
   - Rejects stale callbacks using `expected_state_version` and `expected_turn_id`.

5. **Recovery & Bounded Resend Manager (`app/device_protocol/recovery.py`):**
   - Reconstructs unacknowledged commands from durable database cursor upon reconnect or process restart.
   - Enforces exactly one bounded resend rule (`max_resends = 1`). On first reconnect, re-issues command with `is_resend: True` and increments `resend_count = 1`. On subsequent reconnects without ACK, rejects further resends with `MAX_RESENDS_EXCEEDED`.
   - Processes client ACKs (`DeviceAck`), clearing pending command state.

6. **Device Simulator Integration (`simulators/device_simulator.py`):**
   - Added `create_ack_envelope` helper to `DeviceSimulator` to support end-to-end ACK exchange testing.

7. **Documentation & Architecture Guide (`docs/device-protocol.md`):**
   - Authored comprehensive protocol specification, ASCII state and reconnect sequence diagrams, fault-handling truth tables, reason codes catalog, and architectural invariants.

8. **Unit & Integration Fault-Matrix Test Suites (`tests/unit/test_device_protocol.py`, `tests/integration/test_protocol_fault_matrix.py`):**
